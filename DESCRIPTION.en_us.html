Theeru is an open-source display font family for comics and graphic storytelling from Mooniak, initiated with support from comic artist Sachi Ediriweera.

The font currently covers Sinhala only, designed by Kosala Senevirathne. Mooniak and Sachi plan to extend it to support other languages of the South Asian region.

The project is led by Mooniak. Project sources are hosted and developed on GitHub and Mooniak welcomes suggestions and contributions to the development.
